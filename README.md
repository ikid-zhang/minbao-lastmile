# 民爆"最后一公里"监管系统

公安侧民爆物品"最后一公里"全链路监管演示项目：**小程序原型（纯前端 SPA）+ 设计文档 + 功能清单 + 宣讲 PPT**。

📦 GitHub 仓库：https://github.com/ikid-zhang/minbao-lastmile

## 目录结构

| 路径 | 说明 |
|------|------|
| `miniprogram-prototype/index.html` | 小程序原型入口（390px 手机壳，localStorage 演示数据） |
| `miniprogram-prototype/js/` | data.js（数据层）/ core.js（路由与角色）/ pages-a/b/c.js（页面） |

| `民爆最后一公里监管功能设计说明.html / .md` | 设计文档 V1.3（公安红 HTML + Markdown 源） |
| `ppt/` | 宣讲 PPT（公安蓝，17 页，含构建脚本 build_deck.py） |

## 原型快速体验

直接用浏览器打开 `miniprogram-prototype/index.html`：

- 入口选择角色（9 个角色：项目负责人 / 库管员 / 押运员 / 安全员 / 安全监理 / 民警 / 治安管理员 / 测量技术员 / 安全监管）
- 推荐演示链路：民警审核 PL2 → 库管员（钱有德登记 → 吴秀英复核）勾选 PL2+PL5 合并出库 → 押运员签收（载重校验、路线快选、卸货点调序）→ 逐点到达/逐点核量 → 爆破登记（共核验 + 手签）→ 销毁/退库 → 民警核验
- 「我的」页可一键重置演示数据

## 核心设计要点（详见设计文档 V1.3）

- **三级计划上报**：测量技术员填报 → 安全监管手签 → 项目负责人审核（选库房/公安责任区，当日 24:00 前报次日）
- **出库双人双锁**：登记签名不扣库存 → 第二位库管员复核生效扣库存
- **一单多点**：合并多计划出库，累计载重限制车辆选择，卸货点序列可调序、逐点到达逐点核量
- **沿途打卡点**：运输途中扫码打卡（时间/定位/照片）
- **销毁/退库双分支**：退库押运员扫码确认反向回原库
- **治安管理员 8 类基础数据维护**：公司/点位/库房/四大员/项目备案/负责人（对接可修正留痕）+ 车辆/路线（自录即生效），字段对照《民爆管理表单.et》
- **全链路日志**：每节点留痕，支持按模板导出文件
