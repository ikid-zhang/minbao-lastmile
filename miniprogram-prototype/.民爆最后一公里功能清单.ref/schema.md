# Workbook Design — 民爆最后一公里功能清单

> 由 excel-generation skill 在主代理侧产出，供 sheet-agent 子代理按图施工。

## User Intent
用户此前已有一份 Markdown 功能清单，要求转换为 Excel 格式：表格包含一级功能、二级功能、功能描述三列（主代理补充了「板块」列用于区分企业侧/公安侧/治安管理员/平台公共四大部分）。

## Scenario Archetype
- 记录型：功能台账清单，行级数据、可筛选、冻结表头；无计算、无汇总、无图表。

## Sheets
- 功能清单（角色：主表，全部功能条目）

## Sheet: 功能清单

### Columns
| 列 | 字段名 | 类型 | 来源 | 备注 |
|---|---|---|---|---|
| A | 板块 | 文本 | reference/功能清单/content.md | 枚举：企业侧功能 / 公安侧功能 / 治安管理员功能 / 平台公共功能 |
| B | 一级功能 | 文本 | reference/功能清单/content.md | 如「计划上报」「出库管理」「基础数据维护」 |
| C | 二级功能 | 文本 | reference/功能清单/content.md | 功能点名称 |
| D | 功能描述 | 文本 | reference/功能清单/content.md | 长文本，含业务规则编号（R3/R4/K04/J09 等），原样保留 |

### Sample Data Scale
按 reference/功能清单/content.md 实际条目数量（约 50 行），四个板块顺序：企业侧功能 → 公安侧功能 → 治安管理员功能 → 平台公共功能；跳过 md 中的标题、版本说明行，只取表格数据行。

### Notes for sheet-agent
- 第 1 行表头，数据从第 2 行开始；表头：商务蓝 `#4472C4` 底 + 白字 + 加粗 + 水平居中 + 下边框 thin
- D 列（功能描述）为长文本：列宽 300px + 自动换行（wrapText）+ 左对齐；A/B/C 列宽度由子代理按内容判断
- 数据 ≥ 10 行：开启筛选并冻结表头（冻结第 1 行）
- 同一「板块」的行不做合并单元格，保持每行完整便于筛选排序
- 无公式、无条件格式、无图表

## Charts / Pivots
无

## 约束与不做的事
- 不添加额外 sheet、透视表、图表、统计列
- 不改写功能描述原文（保留业务规则编号）
- 不使用合并单元格
